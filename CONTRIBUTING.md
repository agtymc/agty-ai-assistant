# Участие в разработке

Спасибо за интерес к AGTY AI Assistant. Проект пока находится до полного M0 из `docs/TECHNICAL_SPECIFICATION.md`, поэтому изменения лучше привязывать к конкретному FR/AT из ТЗ или к пункту из `docs/M0_GAP_ANALYSIS.md`.

## Локальная разработка

Требуется JDK 21. Основные команды:

```bash
./gradlew test
./gradlew buildPlugin
./gradlew verifyPluginStructure
```

Если IDEA уже установлена локально, можно передать путь:

```bash
./gradlew test buildPlugin -PlocalIdePath=/absolute/path/to/idea-2025.3
```

В ограниченных средах, где Gradle не может создать lock-сокет или скачать дистрибутив, допустим ручной `javac`-прогон как временная проверка. Для публикации и PR предпочтителен полноценный Gradle CI.

## Правила изменений

- Не храните ключи, токены, локальные настройки IDE и историю чатов в репозитории.
- Для пользовательских сценариев добавляйте или обновляйте тесты.
- Для видимых изменений обновляйте `README.md` и `CHANGELOG.md`.
- Для изменений дорожной карты обновляйте `docs/M0_GAP_ANALYSIS.md`.
- Не заявляйте прохождение проверок, которые не запускались.

## Перед PR

```bash
./gradlew test buildPlugin verifyPluginStructure
```

В описании PR укажите цель изменения, связанные FR/AT из ТЗ, выполненные проверки и известные ограничения.
