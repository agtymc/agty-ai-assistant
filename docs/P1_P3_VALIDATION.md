## Автоматические сценарии

- Сопоставление перемежающихся RPC по ID, EOF, закрытое соединение, независимые подписчики.
- Две параллельные сессии с одинаковыми item ID на одном fake App Server; остановка одной сохраняет выполнение другой и соединение.
- Задача переживает переключение чата, dispose панели и открытие новой панели; ответ сохраняется в исходной сессии.
- Очередь изменяющих задач одного cwd, параллельные независимые каталоги, завершение задач при закрытии runner.
- Предварительная подготовка записи может остановить запуск провайдера при ошибке.
- Интерактивное подтверждение: запрос → явный ответ → resolved → завершение; повторный ответ отклоняется.
- Поток команд и финальный снимок, diff больше 6000 символов, неизвестные элементы, фильтрация непубличных reasoning deltas.
- Ресурсный каталог, не менее двух примеров со сценариями, ссылки, парсинг команд, сохранение неизвестного slash-черновика.
- Auto для новых проектов и сохранение прежних настроек доступа.
