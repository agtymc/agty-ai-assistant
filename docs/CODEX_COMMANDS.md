# Команды Codex — руководство и примеры

Сгенерировано scripts/generate_command_docs.py из ресурсов плагина. Статус реализации и ограничения каждой команды указаны явно.

## Рабочая последовательность

Вставка каждого шага дополняет черновик и не выполняет его автоматически. Plan и права доступа независимы.

Выбрать модель из доступного каталога

```text
/model
```

Добавить файл проекта в явный контекст

```text
/mention <ПУТЬ_К_ФАЙЛУ>
```

Явно подключить экспериментальный контракт для Plan

```text
/experimental on
```

Включить планирование, сохранив режим доступа

```text
/plan on
```

Запросить план

```text
Предложи план реализации задачи и критерии проверки. Пока не меняй файлы.
```

Вернуться к выполнению

```text
/plan off
```

Разрешить запись проекта с интерактивными подтверждениями

```text
/permissions auto
```

Выполнить согласованный план

```text
Выполни согласованный план, сохрани существующие изменения и запусти относящиеся к нему проверки.
```

Посмотреть реальные изменения и доступный безопасный откат

```text
/diff
```

Запросить ревью Codex

```text
/review
```

## /status

Показывает текущую модель, режим доступа и доступные лимиты.

Статус: реализована. Aliases: —

Синтаксис: `/status`.

Когда нужно проверить параметры перед задачей.

UI: Кнопка Status; позднее меню чата.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/status
```

После переключения на другой чат или перед новой задачей.

```text
/status
```

Результат: Карточка статуса; запрос к модели не запускается.

Ограничения: Лимиты требуют доступного CLI и авторизации.

Ошибки: Если статус не загрузился, проверьте путь CLI и авторизацию.

Связанные команды: /model, /permissions

## /help

Открывает офлайн-справочник в редакторной области IDEA.

Статус: реализована. Aliases: —

Синтаксис: `/help [команда]`.

Для знакомства с синтаксисом и примерами.

UI: Меню чата → Справочник команд.

Примеры:

Открыть весь каталог.

```text
/help
```

Перейти к статье выбора модели.

```text
/help model
```

Результат: Активируется одна вкладка справочника, файлы и настройки не меняются.

Ограничения: Работает без сети, CLI и авторизации.

Ошибки: Неизвестное имя: вернитесь к каталогу и используйте поиск.

Связанные команды: /status

## /model

Выбирает модель и effort для следующего turn.

Статус: реализована. Aliases: —

Синтаксис: `/model [ID]`.

Перед задачей или после завершения предыдущей.

UI: Параметры под полем ввода; выбор не создаёт fork.

Примеры:

Открыть список доступных моделей.

```text
/model
```

Выбрать точный ID из списка; замените подставляемое значение.

```text
/model <ID_МОДЕЛИ>
```

Результат: Открывается выбор модели либо выбирается точный ID из доступного каталога; запрос не запускается.

Ограничения: Нужны CLI и доступ модели аккаунту. Во время задачи выбор заблокирован.

Ошибки: Замените <ID_МОДЕЛИ> идентификатором из списка; неподдерживаемый ID отклоняется.

Связанные команды: /permissions, /status

## /new

Создаёт новый локальный чат без контекста прежнего диалога.

Статус: реализована. Aliases: —

Синтаксис: `/new`.

Для независимой задачи; текущая фоновая задача продолжает работать.

UI: Кнопка + Новый чат. /clear в будущем дополнительно сбросит представление; очистка истории не откатывает файлы.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/new
```

После переключения на другой чат или перед новой задачей.

```text
/new
```

Результат: Создаёт пустой чат в текущем рабочем каталоге; старые сообщения, контекст и файлы сохраняются. В отличие от /clear не очищает ручной контекст исходного чата.

Ограничения: Авторизация не требуется до первого сообщения.

Ошибки: Прежний чат доступен в меню Чаты.

Связанные команды: /resume

## /resume

Открывает сохранённый thread Codex в текущем проекте.

Статус: реализована. Aliases: —

Синтаксис: `/resume [UUID]`.

Чтобы продолжить старую работу.

UI: Чаты → Открыть по UID. В отличие от fork продолжает тот же thread.

Примеры:

Открыть список сессий.

```text
/resume
```

Продолжить сессию по UUID из меню Чаты.

```text
/resume <UUID_СЕССИИ>
```

Результат: Загружается история без отправки запроса модели.

Ограничения: CLI, корректный UUID и совпадающий cwd. Не во время задачи выбранного чата.

Ошибки: Возьмите UUID из меню Чаты; сессию другого проекта открыть нельзя.

Связанные команды: /new

## /permissions

Выбирает область доступа к файлам и сети.

Статус: реализована. Aliases: —

Синтаксис: `/permissions [read-only|auto|workspace-write|danger-full-access]`.

Перед задачей, которой нужны изменения.

UI: Переключатели доступа. Глобальная конфигурация Codex не переписывается.

Примеры:

Задать чтение для следующей задачи.

```text
/permissions read-only
```

Включить sandbox проекта с интерактивными подтверждениями для следующей задачи.

```text
/permissions auto
```

Результат: Меняется локальная настройка следующего запроса. Полный доступ требует отдельного явного подтверждения.

Ограничения: Во время задачи режим заблокирован. Auto использует sandbox проекта и on-request; существующие настройки сохраняются при миграции.

Ошибки: Допустимы только перечисленные значения. Режим Plan отделён от прав: планирование само по себе не даёт запись.

Связанные команды: /model, /status

## /stop

Останавливает фоновые терминалы выбранного thread Codex через thread/backgroundTerminals/clean. Текущий turn останавливается отдельно через /interrupt.

Статус: реализована. Aliases: /clean

Синтаксис: `/stop`.

Для остановки задачи только выбранного чата.

UI: Список команд. Семантика изменена относительно 0.13: /stop теперь соответствует CLI; для прежнего действия используйте /interrupt. /clean — alias.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/stop
```

После переключения на другой чат или перед новой задачей.

```text
/stop
```

Результат: Фоновые терминалы выбранной сессии очищаются. Текущий turn не прерывается и файлы не откатываются.

Ограничения: Экспериментальный контракт 0.169.0 должен быть явно включён через /experimental on. Нужен нативный thread.

Ошибки: Если нет thread, сначала создайте чат сообщением. Для остановки текущей задачи используйте /interrupt.

Связанные команды: /interrupt

## /interrupt

Прерывает только текущий turn выбранного чата.

Статус: реализована. Aliases: —

Синтаксис: `/interrupt`.

Если задача пошла в неверном направлении или больше не нужна.

UI: Кнопка ■. Отличается от CLI /stop, который останавливает фоновые терминалы.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/interrupt
```

После переключения на другой чат или перед новой задачей.

```text
/interrupt
```

Результат: Отправляется адресный turn/interrupt; файлы автоматически не откатываются.

Ограничения: Работает для выполняющейся и ожидающей в очереди задачи.

Ошибки: Проверьте, что выбран нужный чат. Для файлов нужен отдельный проверяемый откат.

Связанные команды: /stop, /status

## /diff

Показывает уже сделанные изменения без повторного применения patch.

Статус: реализована. Aliases: —

Синтаксис: `/diff`.

После задачи или перед коммитом.

UI: Меню ⋯ → Изменения кода; действие Сравнение и откат в карточке. /review в будущем запускает ревью модели, /diff сам модель не вызывает.

Примеры:

Открыть изменения последней задачи выбранного чата.

```text
/diff
```

Перейти на вкладку рабочего дерева и сравнить staged, unstaged и untracked файлы.

```text
/diff
```

Результат: Открывается окно с двумя представлениями и штатным Diff Viewer. Откат файла, hunk или задачи требует явного подтверждения и проверки текущей версии.

Ограничения: Для истории без сохранённых исходных версий автоматический откат запрещён. Git нужен для рабочего дерева и вычисления hunks. Не во время изменения того же cwd.

Ошибки: При последующих или несохранённых пользовательских правках откат отклоняется. Откройте сравнение и разрешите конфликт вручную.

Связанные команды: /status, /interrupt

## /clear

Новый чат и очистка ручного контекста. Создаёт новый чат и очищает список ручного контекста. Старые сообщения и файлы сохраняются.

Статус: реализована. Aliases: —

Синтаксис: `/clear`.

Начать независимую задачу после работы с другим набором файлов.

UI: Команды в панели чата; описание и примеры доступны через F1 или /help clear.

Примеры:

Быстрый сценарий: Начать независимую задачу после работы с другим набором файлов.

```text
/clear
```

Другой контекст: после переключения на нужный чат.

```text
/clear
```

Результат: Создаёт новый чат и очищает список ручного контекста. Старые сообщения и файлы сохраняются.

Ограничения: Эталон Codex CLI 0.169.0, IDEA 253. Доступность зависит от текущего чата, авторизации, версии и экспериментального режима. Для изменяющих действий действует выбранная область доступа.

Ошибки: Подставляемые значения в <угловых скобках> замените реальными данными. Если действие недоступно, прочитайте причину рядом с командой и проверьте /status. Повтор задачи при обрыве не выполняется автоматически.

Связанные команды: /new, /resume, /diff

Когда изучена причина отказа и пользователь хочет повторить именно показанную операцию.

UI: Список команд; карточка auto-review объясняет отказ и ссылку на /approve.

Примеры:

После завершения turn выбрать один из последних сохранённых отказов.

```text
/approve
```

В другом чате сначала выбрать его; отказы других чатов не используются.

```text
/approve
```

Результат: После выбора и явного подтверждения вызывает thread/approveGuardianDeniedAction с исходным событием отказа. Повтор проходит как отдельная управляемая задача с версиями файлов и наблюдением, без нового обычного turn/start. Это не изменение общего режима доступа.

Ограничения: Эталонный экспериментальный API 0.169.0, существующий thread и исходный отказ, полученный этим клиентом. Активный turn сначала должен завершиться. Администраторские правила и проверка Codex сохраняют приоритет.

Ошибки: После перезапуска без исходного события повтор недоступен. Неизвестный тип события не подменяется придуманными параметрами. При неопределённом результате соединения действие автоматически не повторяется.

Связанные команды: /permissions, /interrupt, /warnings
