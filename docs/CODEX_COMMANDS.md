# Команды Codex — руководство и примеры

Сгенерировано scripts/generate_command_docs.py из ресурсов плагина. Полный каталог CLI будет покрыт на P5.

## /status

Показывает текущую модель, режим доступа и доступные лимиты.

Синтаксис: `/status`.

Когда нужно проверить параметры перед задачей.

UI: Кнопка Status; позднее меню чата.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/status
```

После переключения на другой чат или перед новой задачей.

```text
/status
```

Результат: Карточка статуса; запрос к модели не запускается.

Ограничения: Лимиты требуют доступного CLI и авторизации.

Ошибки: Если статус не загрузился, проверьте путь CLI и авторизацию.

Связанные команды: /model, /permissions

## /help

Открывает офлайн-справочник в редакторной области IDEA.

Синтаксис: `/help [команда]`.

Для знакомства с синтаксисом и примерами.

UI: Меню чата → Справочник команд.

Примеры:

Открыть весь каталог.

```text
/help
```

Перейти к статье выбора модели.

```text
/help model
```

Результат: Активируется одна вкладка справочника, файлы и настройки не меняются.

Ограничения: Работает без сети, CLI и авторизации.

Ошибки: Неизвестное имя: вернитесь к каталогу и используйте поиск.

Связанные команды: /status

## /model

Выбирает модель и effort для следующего turn.

Синтаксис: `/model [ID]`.

Перед задачей или после завершения предыдущей.

UI: Параметры под полем ввода; выбор не создаёт fork.

Примеры:

Открыть список доступных моделей.

```text
/model
```

Выбрать точный ID из списка; замените подставляемое значение.

```text
/model <ID_МОДЕЛИ>
```

Результат: Открывается выбор модели либо выбирается точный ID из доступного каталога; запрос не запускается.

Ограничения: Нужны CLI и доступ модели аккаунту. Во время задачи выбор заблокирован.

Ошибки: Замените <ID_МОДЕЛИ> идентификатором из списка; неподдерживаемый ID отклоняется.

Связанные команды: /permissions, /status

## /new

Создаёт новый локальный чат без контекста прежнего диалога.

Синтаксис: `/new`.

Для независимой задачи; текущая фоновая задача продолжает работать.

UI: Кнопка + Новый чат. /clear в будущем дополнительно сбросит представление; очистка истории не откатывает файлы.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/new
```

После переключения на другой чат или перед новой задачей.

```text
/new
```

Результат: Выбирается пустой чат; файлы и прежняя история сохраняются.

Ограничения: Авторизация не требуется до первого сообщения.

Ошибки: Прежний чат доступен в меню Чаты.

Связанные команды: /resume

## /resume

Открывает сохранённый thread Codex в текущем проекте.

Синтаксис: `/resume [UUID]`.

Чтобы продолжить старую работу.

UI: Чаты → Открыть по UID. В отличие от fork продолжает тот же thread.

Примеры:

Открыть список сессий.

```text
/resume
```

Продолжить сессию по UUID из меню Чаты.

```text
/resume <UUID_СЕССИИ>
```

Результат: Загружается история без отправки запроса модели.

Ограничения: CLI, корректный UUID и совпадающий cwd. Не во время задачи выбранного чата.

Ошибки: Возьмите UUID из меню Чаты; сессию другого проекта открыть нельзя.

Связанные команды: /new

## /permissions

Выбирает область доступа к файлам и сети.

Синтаксис: `/permissions [read-only|auto|workspace-write|danger-full-access]`.

Перед задачей, которой нужны изменения.

UI: Переключатели доступа. Глобальная конфигурация Codex не переписывается.

Примеры:

Задать чтение для следующей задачи.

```text
/permissions read-only
```

Включить sandbox проекта с интерактивными подтверждениями для следующей задачи.

```text
/permissions auto
```

Результат: Меняется локальная настройка следующего запроса. Полный доступ требует отдельного явного подтверждения.

Ограничения: Во время задачи режим заблокирован. Auto использует sandbox проекта и on-request; существующие настройки сохраняются при миграции.

Ошибки: Допустимы только перечисленные значения. Режим Plan отделён от прав: планирование само по себе не даёт запись.

Связанные команды: /model, /status

## /stop

Временная команда старой версии плагина для остановки turn.

Синтаксис: `/stop`.

Для остановки задачи только выбранного чата.

UI: Кнопка ■. /clean пока не реализован.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/stop
```

После переключения на другой чат или перед новой задачей.

```text
/stop
```

Результат: Отправляется turn/interrupt, уже сделанные файловые изменения сохраняются.

Ограничения: В этой версии ещё имеет старую семантику; CLI /stop останавливает фоновые терминалы. Миграция ожидает P5.

Ошибки: Для остановки текущего turn используйте /interrupt. Если задача уже закончена, действие ничего не меняет.

Связанные команды: /interrupt

## /interrupt

Прерывает только текущий turn выбранного чата.

Синтаксис: `/interrupt`.

Если задача пошла в неверном направлении или больше не нужна.

UI: Кнопка ■. Отличается от CLI /stop, который останавливает фоновые терминалы.

Примеры:

Быстрая проверка или действие в текущем чате.

```text
/interrupt
```

После переключения на другой чат или перед новой задачей.

```text
/interrupt
```

Результат: Отправляется адресный turn/interrupt; файлы автоматически не откатываются.

Ограничения: Работает для выполняющейся и ожидающей в очереди задачи.

Ошибки: Проверьте, что выбран нужный чат. Для файлов нужен отдельный проверяемый откат.

Связанные команды: /stop, /status
