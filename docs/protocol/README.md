# Контракт Codex App Server

Эталон: `codex-cli 0.169.0`; IDEA 2025.3 (253), Java 21. Схемы получены установленным CLI 17 ноября 2026 года без авторизации или обращения к модели.

- `0.169.0/stable/`: генерация без `--experimental`.
- `0.169.0/experimental/`: генерация с `--experimental`.
- Хранятся self-contained bundles (общий и v2), отдельные дублирующие файлы не нужны.

Воспроизведение из корня: `python3 scripts/update_codex_protocol.py`. Скрипт отклоняет другую версию CLI. Эти схемы — контракт, а не заявление о реализации всех методов. Матрица: [CODEX_COVERAGE_MATRIX.md](../CODEX_COVERAGE_MATRIX.md).

| CLI | Контракт | Проверка runtime |
| --- | --- | --- |
| 0.169.0 | зафиксирован stable; experimental отдельно | фиктивный App Server в тестах; реальные сценарии ещё требуют приёмки |
| другие версии | не проверены | совместимость не обещается; feature detection предстоит P1/P5 |

Экспериментальные методы не включать автоматически по номеру версии. Проверять контракт, capabilities, конфигурацию и доступность аккаунту. Изменение baseline требует обновления обеих схем и протокольных тестов. Генерация схем не изменяет глобальную конфигурацию Codex.
